## Agents and open source

- 🪨 **[Enkiplate](https://github.com/virpo/enkiplate)**: Japanese flashcards on an Inkplate e-paper screen. Torn paper, washi, spaced repetition, weather and the next three calendar events.

- 🎛️ **[CMUX Deck](https://github.com/virpo/cmux-deck)**: Stream Deck controls for monitoring and steering several coding agents.
- 🎞️ **[Autoslides](https://github.com/virpo/autoslides)**: Presentations built natively with agents through render-and-review loops.
- 🧰 **[Agent Skills](https://github.com/virpo/agent-skills)**: Opinionated agent workflows forged in real projects.
- ☕ **[Blendo Coffee](https://github.com/virpo/blendo-coffee-ted-ai-vienna)**: A TED AI Vienna experiment showing what 60 minutes of vibe-coding with early Claude Code could produce in 2025.
- 🚩 **[Agentic CTF / Agent Olympics](https://github.com/virpo/ctf-agent-olympics)**: Browser, document, spreadsheet, Slack, and visual challenges made for agents.
- 🏷️ **[Marketplace Seller Agent](https://github.com/virpo/marketplace-seller-agent-skill)**: Turns product photos into researched, priced marketplace listings.
- 🏟️ **[AI Arena / AI Capitan](https://ai-capitan.netlify.app)**: A playful system for making AI adoption visible, social, and competitive.
- 📮 **[Email Spell Checker](https://github.com/virpo/email-spell-checker)**: A tiny TypeScript utility that catches mistyped email domains.
